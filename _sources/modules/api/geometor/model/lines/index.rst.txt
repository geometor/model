geometor.model.lines
====================

.. py:module:: geometor.model.lines

.. autoapi-nested-parse::

   Provides line construction and manipulation for the Model class.

   This module encapsulates the logic for creating symbolic lines from points,
   managing their inclusion in the model, and determining their intersections.

   .. py:method:: construct_line(pt_1: sympy.geometry.Point, pt_2: sympy.geometry.Point, classes: list[str] | None = None, ID: str = '', guide: bool = False, *, intersect: bool | collections.abc.Sequence[geometor.model.element.Struct] | None = None, by: str = '') -> sympy.geometry.Line

      Construct a :class:`sympy.geometry.Line` from two points and add it to the model.

      :param pt_1: The first point of the line.
      :param pt_2: The second point of the line.
      :param classes: A list of class labels.
      :param ID: A string ID for the line. If empty, ``[ A B ]`` is generated.
      :param guide: If True, the line is excluded from automatic intersections.
      :param intersect: Override automatic intersection behavior:
                        - ``None`` (default): uses ``self.auto_intersect``.
                        - ``False``: skip automatic intersections for this line.
                        - ``True``: intersect with all eligible non-guide structures.
                        - ``Sequence[Struct]``: intersect strictly against the given structures.
      :param by: Optional Euclidean citation (e.g., ``"Post.1"``).

      :returns: The constructed or existing :class:`sympy.geometry.Line`.
