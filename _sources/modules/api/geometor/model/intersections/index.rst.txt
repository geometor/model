geometor.model.intersections
============================

.. py:module:: geometor.model.intersections

.. autoapi-nested-parse::

   Closed-form 2D symbolic intersections, Euclidean selectors, and scoped sub-constructions.

   Provides:

   - :func:`intersect_2d`: Exact closed-form solver for 2D ``Line``, ``Circle``, and ``Segment``
     pairs (bypassing SymPy's quartic ``Ellipse`` Gröbner-basis routines).
   - :exc:`ConstructionError`: Raised when a geometric *diorismos* or Euclidean selector fails.
   - :class:`IntersectionsMixin`: Adds :meth:`Model.intersect`, :meth:`Model.intersect_all`, and
     :meth:`Model.subconstruction` to :class:`~geometor.model.Model`.
   - :func:`proposition`: Composable decorator turning any Euclidean construction function into
     a scoped, reusable lemma/problem across ``elements`` and ``etc``.

.. py:function:: intersect_2d(s1: sympy.geometry.entity.GeometryEntity, s2: sympy.geometry.entity.GeometryEntity) -> list[sympy.geometry.Point]

   Compute exact symbolic intersections of 2D lines, circles, and segments.

   Uses closed-form homogeneous cross-products (line-line), orthogonal projection
   discriminants (line-circle), and radical-axis projections (circle-circle) so
   nested radical expressions never fall into SymPy's slow ``Ellipse`` quartic solver.

   :param s1: First 2D geometric entity (``Line``, ``Circle``, or ``Segment``).
   :param s2: Second 2D geometric entity (``Line``, ``Circle``, or ``Segment``).

   :returns: Deterministically sorted list of exact real :class:`sympy.geometry.Point` intersections.

.. py:function:: proposition(prop_id: str, *, g_id: str = '', kind: str = 'problem', title: str = '', hide_guides: bool = True, scope_intersections: bool = True) -> collections.abc.Callable[[collections.abc.Callable[..., Any]], collections.abc.Callable[..., Any]]

   Decorator marking a Euclidean construction function as a composable proposition.

   Executes the wrapped function inside :meth:`Model.subconstruction`, scoping automatic
   intersections to the proposition and automatically marking un-returned auxiliary
   lines, circles, and guide poles with ``guide=True``.

   :param prop_id: Proposition or center identifier (e.g., ``"I.1"``, ``"X(13)"``).
   :param g_id: Optional G-Index node identifier (e.g., ``"G.17"``).
   :param kind: ``"problem"`` (Q.E.F.) or ``"theorem"`` (Q.E.D.).
   :param title: Optional human-readable proposition title.
   :param hide_guides: Default ``hide_guides`` setting when invoked.
   :param scope_intersections: Default ``scope_intersections`` setting when invoked.

   .. py:method:: intersect(s1: geometor.model.element.Struct | sympy.geometry.Segment, s2: geometor.model.element.Struct | sympy.geometry.Segment, *, side_of: tuple[sympy.geometry.Point, sympy.geometry.Point, int] | None = None, other_than: sympy.geometry.Point | collections.abc.Sequence[sympy.geometry.Point] | None = None, on_ray: tuple[sympy.geometry.Point, sympy.geometry.Point] | None = None, beyond: tuple[sympy.geometry.Point, sympy.geometry.Point] | None = None, between: tuple[sympy.geometry.Point, sympy.geometry.Point] | None = None, near: sympy.geometry.Point | None = None, index: int | None = None, ID: str = '', label: str = '', classes: list[str] | None = None, guide: bool = False, by: str = '') -> sympy.geometry.Point

      Compute a targeted intersection of ``s1`` and ``s2`` selected by Euclidean predicates.

      :param s1: First ``Line``, ``Circle``, or ``Segment``.
      :param s2: Second ``Line``, ``Circle``, or ``Segment``.
      :param side_of: ``(A, B, +1|-1|0)`` selecting the half-plane relative to directed line ``AB``.
      :param other_than: Known ``Point`` (or sequence of ``Point`` instances) to exclude.
      :param on_ray: ``(A, B)`` selecting points on ray ``AB`` (:math:`t \ge 0`).
      :param beyond: ``(A, B)`` selecting points on ray ``AB`` strictly past ``B`` (:math:`t > 1`).
      :param between: ``(A, B)`` selecting points strictly between ``A`` and ``B`` (:math:`0 < t < 1`).
      :param near: Reference ``Point`` selecting the closest candidate.
      :param index: Explicit index ``0`` or ``1`` into deterministically sorted candidates.
      :param ID: Optional identifier for the constructed point.
      :param label: Optional alias for ``ID``.
      :param classes: Optional list of CSS/semantic classes.
      :param guide: Whether to mark the point as a guide.
      :param by: Optional Euclidean justification citation (e.g., ``"I.1"``, ``"Post.2"``).

      :returns: The exact :class:`sympy.geometry.Point` registered in the model.

      :raises ConstructionError: If ``s1`` and ``s2`` do not intersect or no candidate matches the selector.
