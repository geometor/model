geometor.model.circles
======================

.. py:module:: geometor.model.circles

.. autoapi-nested-parse::

   Provides circle construction and manipulation for the Model class.

   This module manages the creation of symbolic circles defined by a center point and
   a radius point, handling deduplication and exact symbolic intersections.

      Construct a :class:`sympy.geometry.Circle` from center and radius points.

      :param pt_center: The center point of the circle.
      :param pt_radius: A point on the circumference of the circle.
      :param classes: A list of class labels.
      :param ID: A string ID for the circle. If empty, ``( A B )`` is generated.
      :param guide: If True, the circle is excluded from automatic intersections.
      :param intersect: Override automatic intersection behavior (``None``, ``False``,
                        ``True``, or a ``Sequence[Struct]``).
      :param by: Optional Euclidean citation (e.g., ``"Post.3"``).

      :returns: The constructed or existing :class:`sympy.geometry.Circle`.
