geometor.model.algebra¶

Symbolic canonicalization, exact predicates, and algebraic number field helpers.

This module replaces general-purpose sympy.simplify calls in the hot loop of geometor.model with a tiered algebraic canonicalizer (clean_expr()), fast high-precision + exact symbolic zero/sign predicates (zero_test(), exact_sign()), and explicit sympy.QQ.algebraic_field reducers for quadratic and biquadratic extensions such as \(\mathbb{Q}(\phi)\) and \(\mathbb{Q}(\sqrt{\phi})\).

geometor.model.algebra.fast_line_coeffs(ln: object) → tuple[sympy.Expr, sympy.Expr, sympy.Expr]¶

Extract normalized exact line coefficients (a, b, c) without sp.simplify.

Expands midpoint sums mx, my so conjugate radical terms cancel immediately, strips common sqrt(3) factors (including merged sqrt(3*k) such as sqrt(51)) from equilateral-pole bisector lines in microseconds, and caches the tuple on ln.

geometor.model.algebra.clean_expr(expr: object) → sympy.Expr¶

Canonicalize a symbolic geometric coordinate without invoking sp.simplify.

Applies a fast tiered pipeline:

  1. Immediate O(1) return for Python int and SymPy Rational / Integer.

  2. Fraction combination (sympy.together()), bounded polynomial expansion, and denominator rationalization (sympy.radsimp() with symbolic=False).

  3. Conditional sympy.sqrtdenest() only when nested radicals are actually present.

Parameters:

expr – A numeric value or SymPy expression.

Returns:

A simplified exact sympy.Expr.

geometor.model.algebra.zero_test(expr: object) → bool¶

Determine with 100% mathematical exactness whether expr == 0.

Uses a fast 3-tier decision procedure:

  1. O(1) structural and rational check.

  2. High-precision adaptive evalf(20) rejection for non-zero constant expressions (rejects non-zeros in microseconds without symbolic expansion).

  3. Exact algebraic proof of zero via fraction numerator expansion, clean_expr(), GoldenRatio radical substitution, and fallback simplify / minimal_polynomial.

Parameters:

expr – A numeric value or SymPy expression.

Returns:

True if and only if expr is identically zero.

Return the exact mathematical sign (+1, -1, or 0) of a real expression.

Returns:

geometor.model.algebra.reduce_in_field(expr: object, field_or_gen: sympy.AlgebraicField | sympy.Expr | tuple[sympy.Expr, ...]) → sympy.Expr¶

Reduce an algebraic expression inside an explicit number field \(\mathbb{Q}(\alpha)\).

Handles nested square roots whose radicands simplify to squares inside the target field (such as \(\sqrt{1 + \phi} = \phi\) and \(\sqrt{\phi - 1} = \phi^{-1/2}\) in the Kepler field), and falls back cleanly when outer extensions (e.g. \(\sqrt{3}\)) are present.

Parameters:

  • expr – Numeric value or SymPy expression to canonicalize.

  • field_or_gen – An sympy.AlgebraicField, a generator expression, or tuple of generators.

Returns:

Canonicalized sympy.Expr.
