geometor.model.element¶

Provides core element classes and intersection logic.

This module defines the foundational Element container which wraps SymPy geometric objects with causal ancestry (parents), incident points (pts), classifications (classes), cached numeric coordinates (approx_coords), and IDs.

class geometor.model.element.Element(sympy_obj: sympy.geometry.entity.GeometryEntity, parents: list | None = None, classes: list[str] | None = None, ID: str = '', guide: bool = False)¶

A container for metadata and cached numeric invariants of a model element.

Maintains causal lineage in parents (a true directed acyclic graph), incident points on lines/circles in pts, style/semantic tags in classes, proof diagram markers in markers, and lazily cached numeric coordinates in approx_coords.

Parameters:

  • sympy_obj – The SymPy object representing the geometric entity.

  • parents – A list of causal parent elements.

  • classes – A list of class labels.

  • ID – A string ID for the element. If empty, an ID is generated.

  • guide – If True (or if "guide" is in classes), excluded from auto-intersections.
