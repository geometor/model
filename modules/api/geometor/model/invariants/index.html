geometor.model.invariants¶

Rational trigonometry invariants, projective cross-ratios, and first-class Angle elements.

Implements N. J. Wildberger’s polynomial/rational invariants (quadrance, spread, cross), exact signed orientation and projective cross-ratio / harmonic range predicates, and the first-class Angle element (< B A C )) for Model.

geometor.model.invariants.cross_ratio(A: sympy.geometry.Point, B: sympy.geometry.Point, C: sympy.geometry.Point, D: sympy.geometry.Point) → sympy.Expr¶

Compute the exact projective cross-ratio \((A, B; C, D) = \frac{\overline{AC}\cdot\overline{BD}}{\overline{BC}\cdot\overline{AD}}\).

Projects collinear displacements onto a shared line direction vector so the cross-ratio is computed purely rationally without introducing square roots.

Parameters:

  • A – First base point.

  • B – Second base point.

  • C – First division point.

  • D – Second division point.

Returns:

Exact simplified sympy.Expr.

Raises:

ValueError – If the four points are not collinear or the denominator vanishes.
