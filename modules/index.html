geometor.model¶

Provides the core symbolic data structures, Euclidean construction kernel, and rational-trigonometry proof verifier for 2D constructive geometry in GEOMETOR.

Everything centers around Model.

geometor.model.clean_expr(expr: object) → sympy.Expr¶

Canonicalize a symbolic geometric coordinate without invoking sp.simplify.

Applies a fast tiered pipeline:

  1. Immediate O(1) return for Python int and SymPy Rational / Integer.

  2. Fraction combination (sympy.together()), bounded polynomial expansion, and denominator rationalization (sympy.radsimp() with symbolic=False).

  3. Conditional sympy.sqrtdenest() only when nested radicals are actually present.

Parameters:

expr – A numeric value or SymPy expression.

Returns:

A simplified exact sympy.Expr.

geometor.model.reduce_in_field(expr: object, field_or_gen: sympy.AlgebraicField | sympy.Expr | tuple[sympy.Expr, ...]) → sympy.Expr¶

Reduce an algebraic expression inside an explicit number field \(\mathbb{Q}(\alpha)\).

Handles nested square roots whose radicands simplify to squares inside the target field (such as \(\sqrt{1 + \phi} = \phi\) and \(\sqrt{\phi - 1} = \phi^{-1/2}\) in the Kepler field), and falls back cleanly when outer extensions (e.g. \(\sqrt{3}\)) are present.

Parameters:

  • expr – Numeric value or SymPy expression to canonicalize.

  • field_or_gen – An sympy.AlgebraicField, a generator expression, or tuple of generators.

Returns:

Canonicalized sympy.Expr.

geometor.model.zero_test(expr: object) → bool¶

Determine with 100% mathematical exactness whether expr == 0.

Uses a fast 3-tier decision procedure:

  1. O(1) structural and rational check.

  2. High-precision adaptive evalf(20) rejection for non-zero constant expressions (rejects non-zeros in microseconds without symbolic expansion).

  3. Exact algebraic proof of zero via fraction numerator expansion, clean_expr(), GoldenRatio radical substitution, and fallback simplify / minimal_polynomial.

Parameters:

expr – A numeric value or SymPy expression.

Returns:

True if and only if expr is identically zero.

geometor.model.intersect_2d(s1: sympy.geometry.entity.GeometryEntity, s2: sympy.geometry.entity.GeometryEntity) → list[sympy.geometry.Point]¶

Compute exact symbolic intersections of 2D lines, circles, and segments.

Uses closed-form homogeneous cross-products (line-line), orthogonal projection discriminants (line-circle), and radical-axis projections (circle-circle) so nested radical expressions never fall into SymPy’s slow Ellipse quartic solver.

Parameters:

  • s1 – First 2D geometric entity (Line, Circle, or Segment).

  • s2 – Second 2D geometric entity (Line, Circle, or Segment).

Returns:

Deterministically sorted list of exact real sympy.geometry.Point intersections.

Decorator marking a Euclidean construction function as a composable proposition.

Executes the wrapped function inside Model.subconstruction(), scoping automatic intersections to the proposition and automatically marking un-returned auxiliary lines, circles, and guide poles with guide=True.

Parameters:

  • g_id – Optional G-Index node identifier (e.g., "G.17").

  • kind – "problem" (Q.E.F.) or "theorem" (Q.E.D.).

  • title – Optional human-readable proposition title.

  • hide_guides – Default hide_guides setting when invoked.

  • scope_intersections – Default scope_intersections setting when invoked.

geometor.model.cross_ratio(A: sympy.geometry.Point, B: sympy.geometry.Point, C: sympy.geometry.Point, D: sympy.geometry.Point) → sympy.Expr¶

Compute the exact projective cross-ratio \((A, B; C, D) = \frac{\overline{AC}\cdot\overline{BD}}{\overline{BC}\cdot\overline{AD}}\).

Projects collinear displacements onto a shared line direction vector so the cross-ratio is computed purely rationally without introducing square roots.

Parameters:

  • A – First base point.

  • B – Second base point.

  • C – First division point.

  • D – Second division point.

Returns:

Exact simplified sympy.Expr.

Raises:

ValueError – If the four points are not collinear or the denominator vanishes.
